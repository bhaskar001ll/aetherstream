# Contributing to Aetherstream

Thank you for your interest in contributing to Aetherstream! We welcome contributions from everyone.

## How to Contribute

### 1. Reporting Bugs
- Check the Issues tab to see if the bug has already been reported.
- If not, open a new issue with a clear title and description.
- Provide steps to reproduce the bug and mention your environment.

### 2. Suggesting Enhancements
- Open a new issue explaining the feature you want to add.
- Describe why this feature would be useful for the project.

### 3. Pull Requests (PRs)
1. Fork the repository.
2. Create a new branch for your feature or bug fix (`git checkout -b feature-name`).
3. Make your changes and commit them with clear messages.
4. Push to your branch and open a Pull Request against the `main` branch.

## Code of Conduct
Please note that this project is released with a Code of Conduct. By participating, you agree to abide by its terms.
