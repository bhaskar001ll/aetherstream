## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly:

- **Email:** Send an email to MUFFINHEAD001LL@GMAIL.COM with the details of the vulnerability.
- **What to expect:** We will acknowledge your report within 48 hours and provide a timeline for a fix if the vulnerability is accepted.

Please do not open a public GitHub issue for security vulnerabilities.
